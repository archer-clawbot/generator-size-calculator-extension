THE METHOD

A transparent estimate.

(Total running W + largest extra start W) × (1 + headroom)

Assumes all listed loads run together and only one motor starts at a time. Simultaneous starts can require more capacity. The 15% default is a planning assumption.

Have your installer confirm actual loads, startup behavior, fuel output, and electrical and fuel-system requirements before selecting equipment.
